# Pachet Site Mobil pentru Programări

Un pachet de pagini HTML gata de personalizat pentru servicii locale. Nu necesită server, framework sau abonament: fișierele pot fi deschise direct în browser și apoi încărcate pe orice hosting static.

## Conținut

- `demo-servicii-locale.html` — șablon general pentru servicii locale
- `demo-service-auto.html` — șablon pentru service auto
- `demo-climserv.html` — exemplu pentru servicii HVAC
- `INSTRUCTIUNI.md` — pașii de personalizare și livrare

## Important

Înlocuiește datele demonstrative înainte de publicare: nume, telefon, WhatsApp, email, servicii, program și zone. Nu publica datele de contact din exemple fără acordul proprietarului.
